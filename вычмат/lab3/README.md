# Вычислительная математика, лабораторная работа №3

## Численное интегрирование функций с оценкой погрешности

**Цель работы:** Реализация программы для численного вычисления определенных интегралов от функций (в том числе имеющих разрывы) с использованием трех методов (прямоугольников, трапеций, Симпсона) и автоматической оценкой погрешности по правилу Рунге.

## Основные возможности

- Вычисление интеграла для **7 различных функций** (некоторые имеют разрывы).
- Выбор одного из трех **численных методов** или одновременный расчет всеми тремя.
- Автоматическое **измельчение шага интегрирования** до достижения заданной точности (правило Рунге).
- **Обнаружение и обработка точек разрыва** (для функций 5, 6, 7) с попыткой симметричного интегрирования около разрыва.
- Вывод результатов для методов прямоугольников сразу по трем правилам: **левые, средние, правые**.
- Сравнение с **точным аналитическим значением** (для функций 1–6, где первообразная известна).

## Список функций и их особенности

| Функция | Формула                                                    | Точка разрыва |
| :--- |:-----------------------------------------------------------| :--- |
| `f1(x)` | `3*atan(abs(x+1)) - 2 + 0.2*sin(4(x+1)) - 0.4*cos(2(x+1))` | Нет |
| `f2(x)` | `sin²(2x) - cos²(x)`                                       | Нет |
| `f3(x)` | `sin(x)*cos(3x) + √abs(x) - 1`                             | Нет |
| `f4(x)` | `0.8*abs(x)*ln(abs(x)) - sin(4x) + 1`                      |x|*ln|x| - sin(4x) + 1` | Нет (устранимая в x=0) |
| `f5(x)` | `(x+1)/(x-1) + sin(x-1) - 1`                               | **x = 1** (симметричный разрыв) |
| `f6(x)` | `ln(abs(x)) - x`                                           |x-1| - x + 1` | **x = 1** (несимметричный разрыв) |
| `f7(x)` | `0.5*(9*e^(sin(5x+4)/2) / (x+2)^(1/3))`                    | **x = -2** (несимметричный разрыв) |

## Используемые численные методы

1. **Метод прямоугольников** (левые, средние, правые) — порядок точности `O(h²)`.
2. **Метод трапеций** — порядок точности `O(h²)`.
3. **Метод Симпсона** (парабол) — порядок точности `O(h⁴)`.
4. Введите число 4 в качестве номер метода чтобы посчитать всеми доступными методами

## Входные данные (ввод пользователя)

Программа запрашивает ввод в следующем порядке (разделяя числа пробелом или переводом строки):

1. **Номер функции** — целое число от 1 до 7.
2. **Номер метода** — 1 (прямоугольники), 2 (трапеции), 3 (Симпсона) или 4 (все три).
3. **Границы интегрирования** — два числа `a` и `b` (могут быть отрицательными, `a` не обязательно меньше `b`).
4. **Точность вычислений** `ε` — положительное число (например, `1e-6`).

В любой момент вместо числа можно ввести `exit` для выхода из программы.
## Важное ограничение: несобственные интегралы

Данная программа **не вычисляет несобственные интегралы** в общем случае. Если на отрезке `[a, b]` обнаружена точка разрыва `g` (для функций `f5`, `f6`, `f7`), интеграл считается **расходящимся**, и программа выдаст сообщение об ошибке.

**Исключение:** Если функция является **симметричной относительно точки разрыва** (меняет знак и имеет близкие по модулю значения слева и справа), то интервал автоматически **урезается** — отступ от точки разрыва выбирается таким образом, чтобы обойти сингулярность. В этом случае вычисляется интеграл по усечённому отрезку `[a, a1]` или `[b1, b]` (в зависимости от того, с какой стороны разрыв не мешает интегрированию).

**Пример:**  Например a = -1, b = 2 промежуток -1;1 симметричен относительно 0 с разными знаками  его интеграл равен 0, получается нам надо посчитать только интеграл от 1 до 2, который останется после зануления участка -1; 1
